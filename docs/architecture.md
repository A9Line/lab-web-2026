# Архитектура системы

## Схема из трёх узлов

```
Vue 3 + Vite                ASP.NET Core                PostgreSQL
localhost:5173   ───────►   localhost:5000   ───────►   localhost:5432
                  HTTP                     запросы к БД
             POST /api/waste-requests
```

Под схемой дословно:

> **архитектура web-ИС семестра**

## Пояснение

- **Vue 3 (порт 5173)** — клиент. Рисует экраны: список заявок, форма создания, карточка заявки. Отправляет HTTP-запросы на сервер.
- **ASP.NET Core (порт 5000)** — сервер. Проверяет правила: кто может создать заявку, кто может назначить исполнителя, кто может сменить статус. Обращается к базе данных.
- **PostgreSQL (порт 5432)** — база данных. Хранит заявки, пользователей, лаборатории, типы отходов. Один источник правды о заявках.

## Почему браузер не пишет в PostgreSQL напрямую

Между браузером и базой всегда стоит сервер. Если бы браузер обращался к PostgreSQL напрямую:

- клиент получил бы доступ ко всем данным без проверки прав;
- любой пользователь мог бы обойти правила ролей (инженер мог бы назначить себя исполнителем);
- пришлось бы хранить логин и пароль к базе внутри браузера;
- невозможно было бы проверить обязательные поля на стороне сервера.

Поэтому стрелка «браузер → PostgreSQL» на схеме отсутствует. Клиент общается только с сервером по HTTP, сервер — только с базой.
